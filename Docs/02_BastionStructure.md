# TDD-02. Структура бастиона

## 1. Назначение

`BastionGrid` описывает доступное внутреннее пространство бастиона
и размещение функциональных модулей-отсеков.

Сетка является частью чистого слоя Simulation и не зависит от
Unity Tilemap, GameObject или SpriteRenderer.

## 2. Координаты

Координата клетки состоит из:

- X — горизонтальное положение;
- Deck — номер этажа.

Deck 0 является нижним этажом.

Положительное направление X пока не обозначает нос или корму.
Направление движения бастиона будет храниться отдельно.

## 3. Размеры модулей

Позиция модуля обозначает его нижнюю левую клетку.

Модуль размером 2 × 2 занимает:

- исходную клетку;
- соседнюю клетку справа;
- клетку этажом выше;
- соседнюю верхнюю клетку справа.

## 4. Правила размещения

Модуль может быть размещён, если:

- все занимаемые им клетки находятся внутри сетки;
- ни одна из клеток не занята другим модулем.

Соседние модули могут соприкасаться.

## 5. Ожидаемые ошибки

Неудачная попытка размещения не является исключительной ситуацией.

Возможные причины:

- OutOfBounds;
- Occupied.

Результат возвращается через `ModulePlacementResult`, чтобы интерфейс
конструктора мог показать игроку понятную причину отказа.

## 6. Ограничения первой версии

На первом этапе сетка имеет прямоугольную форму.

В дальнейшем будет добавлена маска корпуса, позволяющая:

- создавать наклонный нос;
- создавать кормовые срезы;
- ограничивать верхнюю надстройку;
- формировать недоступные конструктивные клетки.

Перемещение уже установленного модуля пока не поддерживается.
Для изменения положения модуль удаляется и размещается заново.
