# TDD-02. Структура бастиона

## Назначение

BastionGrid описывает внутреннее пространство и размещение модулей без зависимости от Unity.

## Координаты

- X — горизонтальная координата;
- Deck — этаж;
- Deck 0 — нижний этаж.

Позиция модуля обозначает его нижнюю левую клетку.

## Размещение

Модуль устанавливается, когда все клетки находятся внутри сетки и свободны.

Неудача возвращается через ModulePlacementResult:

- OutOfBounds;
- Occupied.

## Удаление

Удаление освобождает клетки. Bastion дополнительно очищает присутствие и работу бригад, чтобы не оставлять ссылки на удалённый модуль.

## Связность

Полноценный граф проходов ещё не реализован.

Следующий пространственный этап:

- соседство по соприкасающимся клеткам;
- горизонтальные и вертикальные переходы;
- проходимость;
- маршрут между отсеками.

Позднее проходимость будет учитывать двери, лестницы, разрушения, огонь, дым, герметизацию и контроль.

## Ограничения

Сетка пока прямоугольная. Позднее появится маска корпуса. Перемещение установленного модуля выполняется удалением и повторной установкой.
