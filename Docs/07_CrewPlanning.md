# TDD-07. Проектирование экипажа

## Конструктор

В конструкторе бригады не обязаны быть распределены по отсекам.

Рассчитываются:

- требования по WorkType;
- общая численность;
- состав по BrigadeType;
- койки;
- номинальная вместимость;
- аварийная вместимость;
- вентиляционная вместимость.

## Требования

Для каждого WorkType:

- MinimumPersonnel;
- OptimalPersonnel;
- MaximumUsefulPersonnel.

Расчёт ведётся по людям, а не по количеству бригад.

## WorkType

- General;
- Driving;
- Command;
- Gunnery;
- Mechanical;
- Engineering;
- Communications;
- Medical;
- Logistics;
- Assault.

WorkType описывает работу, BrigadeType — специализацию.

## Пригодность

Матрица пригодности BrigadeType к WorkType уже реализована через профили.

Профиль содержит явные проценты для отдельных работ и значение по умолчанию для остальных.

Текущие числа прототипные и позднее могут быть вынесены во внешние файлы игровых данных. Пользовательские названия в профилях не хранятся.

## Жильё

CrewAccommodationFeatureDefinition:

- BerthCount;
- NominalPersonnelCapacity;
- EmergencyPersonnelCapacity.

Номинальная вместимость может превышать число коек из-за вахт.

## Вентиляция

VentilationPersonnelCapacity ограничивает поддерживаемую численность.

Итоговая численность — минимум между жилой и вентиляционной вместимостью.

## MaximumUsefulPersonnel

Это полезные рабочие места, а не жилая или аварийная вместимость.
