# TDD-07. Проектирование экипажа

## 1. Конструктор и оперативный режим

В режиме конструктора бригады не размещаются физически
в конкретных отсеках.

Конструктор рассчитывает:

- потребность конструкции в людях;
- потребность по видам работ;
- фактическую численность экипажа;
- количество коек;
- номинальную жилую вместимость;
- аварийную жилую вместимость;
- возможности вентиляции.

Назначение бригад в отсеки используется только:

- при подготовке к бою;
- в оперативном режиме;
- во время перемещения и выполнения работ.

## 2. Требования по людям

Для каждого вида работы определяются:

- MinimumPersonnel;
- OptimalPersonnel;
- MaximumUsefulPersonnel.

Расчёт производится по людям, а не по количеству бригад.

Игрок самостоятельно определяет размеры и состав подразделений.

## 3. Виды работ

На текущем этапе используются:

- General;
- Driving;
- Command;
- Gunnery;
- Mechanical;
- Engineering;
- Communications;
- Medical;
- Logistics;
- Assault.

WorkType описывает задачу.

BrigadeType описывает специализацию подразделения.

Их соответствие будет рассчитываться отдельной системой пригодности.

## 4. Жилая вместимость

Жилой отсек содержит:

- BerthCount;
- NominalPersonnelCapacity;
- EmergencyPersonnelCapacity.

Номинальная вместимость может превышать количество коек,
поскольку экипаж отдыхает посменно и несёт вахты.

Аварийная вместимость означает кратковременное размещение
с ухудшением отдыха, морали и восстановления усталости.

## 5. Вентиляция

VentilationPersonnelCapacity ограничивает количество людей,
которое бастион способен поддерживать.

Итоговая численность рассчитывается как минимум между:

- жилой вместимостью;
- возможностями вентиляции.

В будущем вентиляция также будет участвовать в:

- удалении дыма;
- отводе тепла;
- распространении пожара;
- защите от заражения.

## 6. Максимально полезный персонал

MaximumUsefulPersonnel не является вместимостью бастиона.

Это количество людей, которое может одновременно приносить пользу
на рабочих местах без переполнения отсеков.

Жилая и вентиляционная вместимость рассчитываются отдельно.
