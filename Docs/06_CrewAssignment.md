# TDD-06. Назначение бригад

## 1. Владение бригадами

Bastion владеет реестром своих бригад.

Бригада может находиться:

- вне рабочего отсека;
- в одном конкретном отсеке.

Одновременное назначение одной бригады в несколько отсеков запрещено.

## 2. Назначение

В один отсек можно назначить несколько бригад.

Бригада назначается целиком и не разделяется на рабочие группы.

Назначение не проверяет максимальную вместимость отсека.
Переполнение разрешено как осознанное решение игрока.

## 3. Удаление

При удалении модуля все назначенные в него бригады
автоматически освобождаются.

При удалении бригады из состава бастиона её назначение
также автоматически удаляется.

## 4. Укомплектованность

Оценка модуля содержит:

- количество назначенных бригад;
- общую численность;
- минимальную численность;
- оптимальную численность;
- максимальную численность;
- средний опыт;
- среднюю мораль;
- среднюю усталость.

Средние показатели взвешиваются по численности людей.

## 5. Состояния

Возможные состояния:

- NotRequired;
- Unstaffed;
- BelowMinimum;
- Functional;
- Optimal;
- AboveOptimal;
- Overcrowded.

Переполнение не блокирует работу, но позднее будет
снижать эффективность из-за тесноты и помех между людьми.

## 6. Ограничения текущей версии

Пока не учитываются:

- специализация бригады относительно выполняемой работы;
- время перемещения;
- состояние маршрута;
- бой за отсек;
- раненые;
- доступность коек;
- эффективность конкретной работы.
