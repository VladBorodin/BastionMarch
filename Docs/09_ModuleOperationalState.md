# TDD-09. Операционное состояние модулей

## Назначение

Операционная оценка объединяет:

- TechnicalState;
- ControlState;
- EffectivePowerMode;
- эффективность работающих бригад;
- переполнение.

## Порядок

1. игрок задаёт RequestedPowerMode;
2. выполняется распределение;
3. определяется EffectivePowerMode;
4. считается работа бригад;
5. применяется переполнение;
6. формируется ModuleOperationalAssessment.

## ModuleOperationalIssue

- Damaged;
- CriticalDamage;
- Destroyed;
- NotFriendlyControlled;
- InactivePowerMode;
- InsufficientQualifiedPersonnel;
- Overcrowded.

Пользовательские названия локализуются в Presentation.

## Повреждения

Прототипные множители:

- Operational: 1.00;
- Damaged: 0.75;
- Critical: 0.40;
- Destroyed: 0.00.

Позднее общий множитель может быть дополнен конкретными неисправностями.

## Блокирующие причины

Активная работа невозможна, если модуль уничтожен, не контролируется игроком, не получил Active или не выполнены минимальные кадровые требования.

Повреждение и переполнение не всегда блокируют работу.

## Механические системы

Нулевой расход энергии не отменяет режим работы. Такой модуль получает Active без затрат, но может быть вручную отключён.

## Ограничения

Пока не учитываются топливо, боеприпасы, запчасти, охлаждение, дым, пожар, маршруты, конкретное действие и модернизации.
